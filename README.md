
# Caça-Rato: O Homem Gol

**Docente:** Ewerton de Oliveira Cercal

## Sobre o projeto

Este projeto é um site sobre o jogador de futebol Caça-Rato, conhecido por sua passagem pelo Santa Cruz. O site apresenta um pouco da sua história, carreira, conquistas e curiosidades.

Também foi criada uma calculadora de desempenho, onde o usuário informa a quantidade de partidas, gols e assistências para calcular suas médias.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
4. Navegue pelo site e teste a calculadora.

## Funcionalidades

- Apresentação da história de Caça-Rato.
- Informações sobre sua carreira e conquistas.
- Imagem com efeito ao passar o mouse.
- Calculadora de desempenho.
- Verificação dos dados informados.
- Mensagens de erro para valores inválidos.
- Adaptação para telas de celular.
